# NgFormSchema

Composable schema operators for Angular Signal Forms.

Designed for Angular Signal Forms / Angular v21+

# ngx-signal-schema Workspace

## Development

```bash
npm install
ng build ngx-signal-schema
ng test ngx-signal-schema
```

## Publishing
```bash
npm publish
```
