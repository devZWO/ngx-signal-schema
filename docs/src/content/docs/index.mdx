## Why ngx-signal-schema?

Angular Signal Forms provide a powerful schema system, but complex forms quickly become difficult to structure.

`ngx-signal-schema` adds reusable composition operators, conditional schema utilities and specialized validators for building maintainable large-scale forms.

```ts
const ContactSchema = append(
  BaseSchema,

  (path) => {
    disabledHidden(
      path.companyName,
      valueEquals(path.personType, 'private')
    );
  }
);
```
